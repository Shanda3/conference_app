# Optional community choices

Names and links were checked against Techlahoma's public [user-group directory](https://www.techlahoma.org/user-groups/) on October 14, 2026, with the additionally verified OklahomAI OKC public Meetup. The catalog is `lib/attendee-social.ts`.

The 19 entries include SheCodesOKC, OKC Coffee and Code, OKC Web Devs, OKC LUGnuts, Oklahoma City Java User's Group, Oklahoma City Open Source Hardware, Oklahoma Game Developers, Oklahoma Salesforce Community, Pythonistas, UX Connect OKC, AWS Tulsa, Tulsa Agile Practitioners, Tulsa Game Devs, Tulsa Tech Entrepreneurs, Tulsa UX, Tulsa Web Devs, Tulsa Developers Association / Tulsa.Net, Urban Coders Guild Professional, and OklahomAI OKC.

OklahomAI OKC uses [its official Meetup](https://www.meetup.com/oklahom_ai/) and the search aliases “OK AI” and “Oklahoma AI,” keeping one stored group ID. SheCodesOKC uses [its official website](https://shecodesokc.org/). Other direct links are the verified Meetups supplied in the source research.

UX Connect OKC's directory-listed Meetup returned group-not-found; Tulsa Tech Entrepreneurs had no verified direct public URL; Urban Coders Guild Professional's listed Slack requires workspace membership. These three use the official directory rather than guessed URLs. Sparse event listings were not treated as proof a community is inactive. Optional umbrella Meetup groups were not added as duplicate memberships.

Catalog inclusion describes a public community resource, not verified attendee membership, partnership, endorsement or enrollment. Member/interested labels are empty until an attendee explicitly saves their own choices; they are visible only to signed-in conference attendees. External links send no Devyo contact information and use `no-referrer`.
